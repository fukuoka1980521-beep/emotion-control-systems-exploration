# Experiment Index

This index records the exploratory sequence and the main interpretation retained after corrections.

## V1 — Minimal attachment model

**Question:** Can learned attachment to a specific target generate emotion-like behavior without named emotion variables?

**Retained observation:** stronger attachment increased protection under threat, search after loss, and positive value change on restoration.

**Boundary:** these were functional analogues only; the reward structure already made the target valuable.

## V2 — One variable, multiple contexts

**Question:** Can a single persistent attachment variable produce fear-, frustration-, grief-, joy-, and jealousy-like patterns depending only on context?

**Retained observation:** threat, obstruction, loss, and restoration differentiated. Jealousy-specific behavior did not emerge.

**Revision forced by failure:** attachment alone could not distinguish 'I cannot access the target' from 'another agent has the target.' Social comparison or exclusivity required additional representation.

## V3 / V3.1 — Actor-directed response

**Question:** What changes simple obstacle removal into an anger-like response directed at an actor?

**Initial result:** intentional and unjustified obstruction increased confrontation/sanction.

**Problem found:** V3 allowed actor-directed actions even when no actor existed in one condition.

**Correction:** V3.1 removed that invalid option. The differentiated pattern remained.

**Boundary:** V3 still contained human-designed rules giving value to intervention against intentional/unjustified obstruction.

## V4 — Learned actor-specific intervention

**Question:** Can direct intervention be learned from outcomes without explicit concepts of malice, fairness, or anger?

**Retained observation:** identity-specific memory allowed agents to differentiate a persistent interferer, an accidental interferer, and a protective gatekeeper.

**Ablation:** pooling all actor identities destroyed the differentiation.

**Interpretation:** attachment plus identity-specific memory and outcome learning can generate part of the function associated with anger-like social control.

## V5 / V5.1 — Resentment-like persistence

**Question:** After a repeated interferer fully reforms, can negative actor-directed policy persist?

**Initial result:** strong persistence appeared under slow/cumulative updating.

**Problem found:** policy lock-in meant the agent often failed to sample actions that would reveal the actor had changed.

**Correction:** V5.1 added exploration/probing.

**Retained interpretation:** persistence depends not only on memory strength but also on which new evidence behavior permits the agent to observe.

## V6 — Betrayal and expectation gap

**Question:** If physical harm is identical, does prior expectation change internal response?

**Retained observation:** harm from a previously helpful actor generated a much larger negative prediction error than the same harm from an already-hostile actor.

**Important negative finding:** the largest prediction error did not automatically produce the strongest punitive response.

**Interpretation:** 'shock from betrayal' and 'belief that punishment/control is useful' are distinct computational quantities.

## V7 / V7.1 — Self-model threat

**Question:** Can different self-conscious emotion-like functions arise when a valued self-model is damaged in different dimensions?

**Self-model dimensions:** competence, social regard, integrity.

**Initial problem:** V7 gave repair benefits even when the corresponding self-dimension had not actually been damaged, creating a false positive.

**Correction:** V7.1 constrained improve/defend/repair actions to contexts where they could actually restore the damaged dimension.

**Retained observation:** private competence failure favored improvement; false public insult favored defense; self-caused moral violation favored repair.

**Boundary:** this is not evidence of subjective shame, humiliation, or guilt.

## V8 / V8.1 — Body state and closed-loop control

**Question:** Does internal body state change the intensity, decisiveness, and persistence of emotion-like control?

**V8:** fixed arousal, fatigue, and pain states changed defensive action distributions.

**V8.1:** body state was then generated dynamically from threat, damage, and action, and fed back into later action selection.

**Retained observation:** body feedback, memory, behavior, and environmental outcomes formed a closed loop that changed later responses to weaker threat.

## Current integrated model

The initial idea 'emotion comes from attachment' was too simple.

The current hypothesis-generating model is:

> value / attachment
> + event and actor representation
> + memory
> + prediction and prediction error
> + learning/update dynamics
> + information sampling behavior
> + self-model
> + body-state feedback
> → emotion-like functional control patterns

The model is intentionally stated as a computational control account, not a claim about phenomenal consciousness.

## Next scientific step

Do not add more mechanisms merely to make the model richer.

The next high-value step is to derive predictions that differ from existing theories and test them against external human or animal data. Candidate predictions should be preregistered before looking at the target dataset whenever feasible.
