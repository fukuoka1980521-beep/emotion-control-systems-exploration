# 感情は「執着」から生まれるのか？

**Emotion Control Systems Exploration**  
**福岡 忍 / Shinobu Fukuoka**

**公開版 v1.0**  
**DOI: `10.5281/zenodo.22780290`**  
**Zenodo: https://zenodo.org/records/22780290**

この研究は、私がChatGPTとの会話の中でふと思った、かなり素朴な疑問から始まりました。

> **感情につながる一番の道は、執着なんじゃないか？**

大切なものを失いたくないから怖くなる。  
失えば悲しい。  
戻ってくればうれしい。  
邪魔されれば腹が立つ。

では、人工的なエージェントに「恐怖」「悲しみ」「怒り」といった感情名を直接与えず、**価値あるものへの執着だけ**を持たせたら、どこまで感情に似た行動が出るのか。

面白そうだったので、小さな計算実験を作って実際に試しました。

最初は、執着だけでかなり説明できるのではないかと思っていました。ところが続けるほど、そう簡単ではないことが分かりました。

**嫉妬が出ない。**  
**怒りらしい反応には「誰がやったか」が必要になる。**  
**古い評価が残る理由の一部は、記憶ではなく新しい証拠を見に行かないことだった。**  
**同じ被害でも、信頼していた相手から受けると予測誤差が大きくなる。**  
**でも、ショックが大きいことと制裁が強いことは同じではなかった。**  
**自分自身についてのモデルを傷つけると、修復行動の種類が変わる。**  
**身体状態まで閉ループに入れると、後の弱い脅威への反応まで変わる。**

そうやって、最初の仮説を証明するというより、**実験で壊しては作り直す**ことをV1からV8.1まで繰り返しました。

このリポジトリは、その記録です。

## 先に、誤解されたくないこと

この研究で「AIに本物の感情が生まれた」とは主張しません。

シミュレーションの中で起きたのは、あくまで**感情の一部に似た機能的な行動パターン**です。

- 大切な対象が危険になると守ろうとする
- 対象を失うと探し続ける
- 反復して邪魔する相手には、その相手へ直接対処する
- 過去の学習によって相手への反応が残る
- 自分の能力・評判・一貫性が傷つくと、異なる修復行動を取る

こうした挙動を、便宜上「恐怖様」「悲嘆様」「怒り様」などと呼んでいます。

**行動が似ていることと、主観的に感じていることは別です。**

また、計算感情、強化学習と感情、appraisal theory、homeostatic regulation、interoceptionなどには長い先行研究があります。この研究は「世界初の感情理論」ではありません。

私が面白いと思っているのは、**一つの素朴な仮説から始め、否定された結果や設計ミスも残しながら、必要な構造を一つずつ見つけていった過程**です。

## 現在の作業仮説

最初の「執着だけで感情を説明できるのでは」という考えは、そのままでは残りませんでした。

今のところ、私は次のように考えています。

> **執着は、感情そのものではなく、反応の重みを作る土台の一つかもしれない。**
>
> そこに、記憶、相手の識別、将来予測、予想と現実の差、自分についてのモデル、身体状態などが重なり、異なる感情様反応へ分岐する。

かなり乱暴に書けば、現在の候補モデルはこうです。

> **emotion-like response ≈ value / attachment × world model × memory × prediction error × self-model × body state**

さらに、古い評価がどれくらい速く更新されるか、そして自分が新しい証拠を見に行くかどうかによって、反応の持続時間も変わりました。

これは「人間の感情はこうできている」という結論ではなく、**次に人間や動物のデータで壊せる仮説を作るためのモデル**です。

## 実験の流れ

| Version | 試したこと | 何が起きたか |
|---|---|---|
| V1 | 執着から単純な感情様行動が出るか | 保護、喪失後の探索、再会時の価値変化が出た |
| V2 | 執着1変数だけで複数の反応が出るか | 恐怖様・悲嘆様・喜び様は出たが、**嫉妬は出なかった** |
| V3 / V3.1 | 単なる妨害と怒り様反応は何が違うか | 原因主体、故意性、不当性が重要。設計漏れをV3.1で修正 |
| V4 | 「悪意」を教えなくても相手への直接介入を学ぶか | 人物記憶と経験だけで相手ごとの反応が分化 |
| V5 / V5.1 | 相手が改心しても負の反応は残るか | 記憶だけでなく、新しい証拠を見に行かないことが持続を強めた |
| V6 | 同じ被害でも裏切りは違うか | 信頼履歴で予測誤差は変わるが、ショックと制裁は別だった |
| V7 / V7.1 | 自分自身を執着対象にすると何が起きるか | 能力、社会的評価、一貫性の損失で異なる修復行動へ分岐 |
| V8 / V8.1 | 身体状態を入れるとどうなるか | 覚醒・疲労・痛み・記憶・行動が閉ループを作り、後の反応まで変化 |

詳しい実験索引は [`docs/EXPERIMENT_INDEX.md`](docs/EXPERIMENT_INDEX.md) にあります。

## この研究で大事にしている失敗

途中で何度も、もっともらしい結果が「本当にそうなのか？」という問題にぶつかりました。

- V2では、執着だけでは嫉妬が出なかった
- V3では、自然障害なのに存在しない相手を攻撃できる設計漏れがあった
- V5では、「恨み」に見えた一部が**policy lock-in**でも説明できた
- V6では、「信頼相手の裏切りほど強く制裁する」という予想は成立しなかった
- V7では、自己モデルが傷ついていない外部損失でもrepairが有利になる偽陽性があり、V7.1で修正した

こうした結果は消していません。

**うまくいかなかった結果の方が、仮説を次へ進めたことが何度もあったからです。**

研究上の扱い方は [`docs/RESEARCH_INTEGRITY.md`](docs/RESEARCH_INTEGRITY.md) にまとめています。
