# 実験ファイルの見方

ここには、V1〜V8.1のうち、公開用に整理できた実験から順に置いています。

最初から全部が論文用の形で保存されていたわけではありません。会話しながらその場で試した実験もあるため、**「結果が残っている」ことと「第三者が同じコードで再実行できる」ことを分けています。**

## 現在、再実行して保存値と完全一致したもの

- `v5_1/` — 改心後の反応持続、探索とpolicy lock-in
- `v6/` — 裏切りと期待誤差
- `v7_1/` — 自己モデル損傷と修復行動
- `v8_1/` — 身体状態を含む閉ループ

それぞれのフォルダに、

- `reproduce_*.py` — 再実行コード
- `preserved_*.csv` — 実験当時に保存した公開対象の数値

があります。

ルートで次を実行すると、4本を再実行して保存値と完全一致するか確認できます。

```bash
pip install -r requirements.txt
python tools/validate_reproductions.py
```
